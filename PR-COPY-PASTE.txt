# 🚀 IEDC SUMMIT 2025 - Alumni Crowdfunding Platform

## 📋 Overview

This PR adds a complete standalone crowdfunding platform for IEDC SUMMIT 2025, enabling LBSCEK alumni to support the event through donations.

## ✨ What's Included

### 💰 Complete Crowdfunding Platform
- **Frontend:** React 18 + Vite 5 + Tailwind CSS 3
- **Backend:** Express.js 4 with RESTful API
- **Database:** Supabase (PostgreSQL + Storage)
- **Documentation:** 15+ comprehensive guides

### 🎯 Key Features

#### Donation System
- ✅ 5-step donation flow with intuitive UI
- ✅ Support for India and International donations
- ✅ UPI and Bank transfer payment options
- ✅ Payment proof upload (images/PDFs)
- ✅ Anonymous donation option
- ✅ Batch information collection
- ✅ PAN collection for large donations

#### Display Features
- ✅ Real-time donor wall with latest contributions
- ✅ Alumni testimonials section
- ✅ Countdown timer (funding closes Dec 19, 2025)
- ✅ Impact section showing fund allocation
- ✅ Transparency commitment section
- ✅ Event details and information

#### Design & UX
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Modern UI with smooth animations
- ✅ Accessible design patterns
- ✅ Fast loading with Vite
- ✅ Professional styling with Tailwind CSS

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/donations` | Fetch verified donors for donor wall |
| POST | `/api/donations` | Submit new donation with proof |
| GET | `/api/testimonials` | Fetch alumni testimonials |
| GET | `/api/health` | Health check endpoint |

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your Supabase credentials

# Run development server
npm run dev
```

**Servers start at:**
- Frontend: http://localhost:3000
- Backend: http://localhost:5000

## 📦 Integration Options

### Option 1: Subdomain (Recommended)
Deploy at `crowdfunding.iedclbscek.com` or `summit.iedclbscek.com`

**Pros:**
- Independent deployment
- Easy to maintain
- No impact on main website
- Can scale independently

### Option 2: Subdirectory
Integrate at `/crowdfunding` or `/summit-2025` on main website

**Pros:**
- Same domain
- Unified navigation
- Shared authentication (if needed)

### Option 3: Standalone with Links
Deploy separately and add prominent links/CTAs on main website

**Pros:**
- Fastest to implement
- No main website changes needed
- Can launch immediately

See `INTEGRATION-GUIDE.md` for detailed instructions on all options.
